# 검증 결과와 출시 제한

`1.0.0-alpha01` 출시 준비 기준입니다. 아래 결과는 패키지와 예제의 동작 확인이며, 앱인토스 검수 통과를 의미하지 않습니다.

| 검사 | 확인 범위 |
| --- | --- |
| JS 테스트 | 브리지·CLI·버전별 npm 배포 채널 테스트 29개 |
| JVM 테스트 | SDK 계약 6개, 공통 API 클라이언트 2개 |
| 린트 | 저장소와 생성 앱의 JS·TS·Kotlin·Gradle |
| 생성 CLI | 대화형 입력, 파일·심볼릭 링크 보호, 기본·전체 타깃, immutable 설치, Wrapper·CI 복원 |
| 배포물 | Maven POM·소스·Javadoc·내부 JS 리소스, CLI 버전·SDK 좌표·vendor 제외 |
| 서명·게시 사전 검사 | 임시 PGP 키로 서명 22개 검증, Central·npm 게시 dry run |

개발용 Maven 바이너리는 Git에 보관하지 않고 `yarn template`에서 생성합니다. 정식 CLI 배포물은 Maven Central을 사용합니다. 실제 게시와 실사용 인증은 릴리스 태그 실행 전까지 미검증입니다.

## 예제에서 확인한 범위

이번 alpha 배포물의 생성 앱은 Android SDK 환경 변수 없이 JS/Wasm 호환 배포와 `.ait` 생성을 통과했습니다. 기본·전체 타깃 생성 앱의 설치·린트·JVM 테스트와 SDK 리소스 추출도 통과했습니다.

초기 구현에서 앱인토스 JS/Wasm 호환 배포와 `.ait` 생성, 독립 웹 배포, Android debug 빌드, iOS arm64 시뮬레이터 빌드를 확인했습니다. Aside로 한글 표시·목록/상세 이동·초안 저장·복원·mock 로그인을 확인했습니다. 이 결과는 이번 alpha 버전의 기기 실행 검사를 대신하지 않습니다.

## 출시 전 확인할 항목

- 실제 Android·iOS 토스앱의 인증·공유·호스트 이벤트·생명주기와 검수
- Canvas UI의 접근성·입력·화면 여백·로딩·메모리·스크롤 성능과 구형 WebView 대체 실행
- 앱인토스 디자인 적합성 및 TDS 모달 조건. 현재 공통 UI는 Material 3이며 TDS 통합은 미구현
- Windows의 설치·빌드 경로와 네이티브 기기 UI
- iOS 최소 버전 16.0 실행. 기존 빌드에는 ICU 객체와 앱 최소 버전 차이 경고가 있었음

Aside의 초기 스냅샷에는 Canvas만 표시돼 전체 Compose 시맨틱 트리를 검증하지 못했습니다. 한글 폰트를 포함해 화면 표시를 확인했지만 전송량·시작 시간은 측정하지 않았습니다. 자세한 버전 조건은 [호환성](compatibility.md), 서비스와 패키지 게시 절차는 [출시 준비](release.md)를 참고하세요.
