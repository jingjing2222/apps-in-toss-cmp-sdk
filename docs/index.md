예제 실행 명령은 별도 표시가 없으면 SDK 저장소 루트를 기준으로 합니다. CLI로 생성한 앱에서는 생성된 앱의 개발 가이드를 따릅니다. 생성 앱의 Gradle 모듈에는 `:sample:` 접두사가 없습니다.
